# Representation scale

The compiler chooses, per entity, the smallest scale that keeps the causal differences
that matter, and records why each material party is included or excluded
(`structure_rationale`, `world_review`).

## The test for inclusion

Not "who performs the terminal act" but "who or what could materially change whether it
occurs". For every candidate party: if it were absent, could the answer differ? If yes,
it belongs in the world — as an actor, an entity a process carries, an information
channel, or an external process. If no, it is left out with a stated reason. A party
whose decisions cannot move any term the terminal reads is decoration, and the run is
refused for it.

## The scales

* **individual** — when one person genuinely controls the outcome.
* **organization acting as one unit** — when internal individual differences do not
  change the outcome.
* **subunit** — when units within an organization face materially different constraints.
* **population_stratum** — segments that respond differently (demand by geography, income,
  financing sensitivity), never one generic multiplier and never a million individual
  agents.
* **external_process** — throughput, markets, administrative clocks, physical processes
  that no social actor controls.

## Aggregate cardinality

An aggregate is a compression, not a reduction. A coalition of seven countries deciding
as one unit is **one actor with `represents_count` 7**, never one participant. Every gate
that asks how many participants there are counts represented members
(`reality.represented_member_count`), not simulation objects — a live OPEC+ run was
refused for "declaring more participants than it contains" by a check that counted rows.

The real decision rule governs whatever number of objects represents the body: a
five-of-nine threshold needs five of nine. A real threshold is never rewritten to fit the
object count, and material internal disagreement is never hidden inside an aggregate — if
members can differ in a way that changes the outcome, they are compiled separately.
